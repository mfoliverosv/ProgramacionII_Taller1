
## ¿Qué hace?
Este programa solicita los datos básicos de un cliente del consultorio odontológico y calcula el valor total de una cita.

## Datos solicitados
- Cédula.
- Nombre.
- Teléfono.
- Tipo de cliente: Particular, EPS o Prepagada.
- Tipo de atención: Limpieza, Calzas, Extracción o Diagnóstico.
- Cantidad de atenciones.
